Multi-Crate Workspace Architecture

A modular Rust design separating presentation, layout calculation, networking, and platform shells.

Crate Role Description
false-ui Native Shell & UI Tauri 2.0 window coordinator, GUI installer/uninstaller, and dark webview host.
false-engine Engine Orchestrator Integrates DOM, CSS cascade, layout calculator, and rendering painter.
false-dom HTML Tree Parser Pure-Rust HTML tokenizer and strict DOM node hierarchy generator.
false-css CSS & Cascade Core Selector matching, specificity resolution, and computed property cascades.
false-layout Box Tree Generator Block and inline formatting context geometry computation.
false-render Raster Engine Software and hardware surface rasterizer with zero-allocation render loop.
false-net Async Networking High-throughput connection multiplexing and resource stream caches.
false-core State & Data SQLite-backed bookmark storage, search history, and persistent session state.

v0.1.0 Latest Release
November 2026
  • Standalone GUI Installer: Introduced single-binary FalseSetup.exe with isolated WebView2 profile, zero CMD window popups, and instant launch under 150ms.
  • Native Windows Integration: Fast VBScript shortcut creation (15ms) for Desktop (False.lnk) and Start Menu, plus native Control Panel Uninstall registration.
  • Modular Update Format (.flse): Self-contained packaging format allowing drag-and-drop runtime upgrades without full re-installation.
  • Hardware Accelerated Chromium Engine: Integrated zero-copy video decoding, GPU rasterization, multi-threaded raster threads, and QUIC/HTTP3 direct networking.
  • Resolved OAuth & Popup Flows: Eliminated intrusive link and window hijacking to allow seamless Google, GitHub, and Discord account sign-ins.
  • Pure-Rust Engine Workbench: Functional HTML/CSS layout and raster pipeline accessible directly via false://workbench.
